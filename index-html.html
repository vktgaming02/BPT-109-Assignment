Block Diagram of a Computer

Understanding • Explain
Explain the flow of data, instructions, and control signals within the functional block diagram, detailing interaction between CPU, memory unit, and I/O interface.
Data / instruction flow (solid)Control signals (dashed)

Explanation

  • Data flow: Input devices convert user data into binary and send it via the I/O interface to memory. The ALU gets data from memory/registers, processes it, and sends results back to memory or out to the output device.
  • Instruction flow: Programs are stored in memory. The Control Unit fetches each instruction, decodes it, and then executes it (fetch-decode-execute cycle).
  • Control signals: The Control Unit does not process data itself. It sends timing and command signals to the ALU, memory, and I/O devices so every part works in the correct order.
  • Interaction: CPU ↔ Memory (read/write through buses); CPU ↔ I/O interface (the interface matches the speed and format of slow devices with the fast CPU).

Compare point-and-draw devices (mouse, trackball) with graphics digitizers/drawing tablets: coordinate tracking and pressure sensitivity for CAD and digital art.

🖱️ Mouse / Trackball

  • Tracking: relative (change in position)
  • Pressure: none (only click)
  • Precision: moderate; lifting and repositioning needed
  • Best for: general pointing, basic CAD selection

✏️ Digitizer / Drawing Tablet

  • Tracking: absolute (tablet area = screen area)
  • Pressure: 1,024-8,192 levels (stroke thickness/opacity)
  • Precision: high; pen-like natural control
  • Best for: tracing drawings in CAD, digital art, signatures

Facial vs Voice Recognition for Authentication

Evaluating • Critique
Critique reliability and security vulnerabilities of vision-input (facial recognition) vs voice recognition as primary biometrics in high-noise, publicly exposed environments.

👁️ Facial Recognition

Strengths: Not affected by noise; fast, contactless.

Weaknesses: Poor lighting, glare, rain, masks, caps/glasses lower accuracy; spoofing with photo, video or 3D mask; privacy concerns as faces are visible in public.

🎙️ Voice Recognition

Strengths: Hands-free, cheap hardware.

Weaknesses: Background noise and crowd talk corrupt the signal; voice changes with cold or stress; replay attacks (recordings) and AI voice cloning; others can overhear passphrases.

Critique: In loud, public places, voice recognition is the weaker choice, since noise directly damages its input and recordings are easy to replay. Facial recognition is more dependable there, though it needs good cameras, liveness detection (blink/depth checks) and privacy safeguards. Best practice: use face as primary and add a second factor (PIN or card) rather than relying on any single biometric.
